# Baby Stuff — SideStore source

Add this URL in SideStore → Sources → `+`:

```
https://raw.githubusercontent.com/WongFam/baby-stuff-sidestore/main/source.json
```

Builds are unsigned; SideStore signs them with your Apple ID. The app
requires iOS 27 and an allow-listed Google account on baby.wongfam.io.
The app's source lives in the private `WongFam/baby-stuff-ios` repo, whose
release workflow publishes here.
